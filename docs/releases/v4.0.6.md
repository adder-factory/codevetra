# CodeVetra v4.0.6

Updates Rust and dependencies while preserving native storage and cancellation contracts.

## Changes

- Pins Rust 1.100.0 across production, CI, Linux build images, and the isolated
  Shuttle harness; the source edition remains Rust 2024.
- Updates Jiff to 1.0.0, lz4_flex to 0.14.2, and compatible transitive dependencies.
  Safe LZ4 encoding and decoding remain explicitly enabled.
- Uses standard-library `DropGuard` for request cancellation, dismissing cleanup
  only after a completed result is delivered. Project-owned work remains retained
  until completion, including after callers disappear.
- Adopts current Rust optional-value helpers and resolves the new strict Clippy
  findings without relaxing lint settings or frozen extraction expectations.
  Single-suffix trimming preserves UTF-8 byte offsets and CRLF source positions.
- Enables Cargo dependency-use checks and schedules updates for the independent
  Shuttle workspace. Kani, Verus, and Shuttle retain enforced resource limits.

## Upgrade

Run `codevetra upgrade --apply --project-path <PATH>` and restart existing owners.
Source builds require Rust 1.100.0. Existing native generations remain compatible.
Legacy names still require the
[migration guide](https://github.com/adder-factory/codevetra/blob/main/docs/CODEVETRA-MIGRATION.md).

**Compatibility:** native Rust and per-project RocksDB 11.12.0 remain the only runtime/storage path. RocksDB format v1 and generation contract V27 are unchanged.
