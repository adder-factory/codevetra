# CodeVetra v4.0.2

Repairs large-project biomarker refreshes and source-rich exploration across CLI and MCP.

## Changes

- Biomarker refresh retains compact document references and reads detailed
  metrics from the immutable snapshot as needed, preventing unnecessary
  workspace exhaustion while preserving complete counts and existing limits.
- Refresh failures distinguish capacity exhaustion, changed generations, and
  invalid detector records instead of returning only `Tool execution failed`.
- Refresh output identifies the native generation-fenced detector relation.
- Exploration retains its full native source allocation while limiting optional
  navigation seeds to 20 windows and reporting omitted provider evidence.
- CLI contract tests cover command routing and help for every advertised MCP tool.
- MCP budget diagnostics report writes as disabled for the read-only profile.

## Upgrade

Run `codevetra upgrade --apply --project-path <PATH>`, then restart the MCP host.
Refresh biomarkers after upgrading; detector cache fingerprints invalidate earlier results automatically.
Existing Cartograph installations must first follow the [name migration guide](https://github.com/adder-factory/codevetra/blob/main/docs/CODEVETRA-MIGRATION.md).

**Compatibility:** native Rust with per-project RocksDB 11.12.0 remains the only runtime/storage path. RocksDB format v1 and generation contract V27 are unchanged; existing source graphs remain compatible.
