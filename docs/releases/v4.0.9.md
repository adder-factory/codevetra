# CodeVetra v4.0.9

## Changes

- Follow proven Rust receiver calls to methods in the same root inherent implementation,
  including implementations of re-exported types.
- Find test-owned Rust callers inside production files and see their named declarations
  in the test lookup.
- Implementation traces prioritize matching functions and methods for follow-up while
  retaining fields and other supporting search results.
- Doctor reports model-specific embedding coverage, vector-index and query-probe
  readiness, and the repair command for incomplete coverage.

## Upgrade

Run `codevetra upgrade --apply --project-path <PATH>`, restart existing MCP hosts,
and re-index source once for generation contract V36.

**Compatibility:** Rust 1.100.0 and edition 2024; native Rust and per-project RocksDB 11.12.0; RocksDB format v1 and generation contract V36.
